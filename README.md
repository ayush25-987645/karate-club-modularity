# Modularity on the Karate Club Graph

**Course:** DSC212 — Graph Theory

## Project overview
This project applies spectral methods and recursive bisection to identify communities in the Zachary Karate Club graph.

## Methods
- Construction of the adjacency and modularity matrices
- Spectral community detection using eigenvalues and eigenvectors
- Recursive community bisection
- Calculation of modularity and network centrality measures
- Visualization of communities and analysis of network metrics

## Requirements
- Python
- NumPy
- NetworkX
- Matplotlib
- Jupyter Notebook

## How to run
Open `karate_club_modularity.ipynb` in Jupyter Notebook or VS Code and run the cells from top to bottom.
